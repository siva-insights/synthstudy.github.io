# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it via a [GitHub private security advisory](https://github.com/siva-insights/synthstudy.github.io/security/advisories/new) so it can be triaged before public disclosure.

For non-sensitive issues, opening a regular [GitHub Issue](https://github.com/siva-insights/synthstudy.github.io/issues) is fine.

## Local helper (OLSEDG Helper)

The local helper restricts incoming requests to the app's origin via an Origin allowlist, and locks CORS to that same origin.
